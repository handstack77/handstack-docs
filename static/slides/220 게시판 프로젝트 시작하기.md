게시판의 요구사항을 화면·DB·계약으로 나누고 한 번의 조회를 연결합니다.

## 왜 게시판 프로젝트인가? (1/2)

<!-- _class: reference-page -->



처음 개발을 시작할 때 게시판 만들기는 가장 기본적인 프로젝트로 권장됩니다.
게시판 예제는 HandStack 기반 개발의 핵심 개념을 이해하고 실습하는 데 매우 유용합니다.

- 웹 페이지 화면 구성
  - Tabler CSS Framework 기반의 레이아웃과 디자인 학습

- 서버 데이터 통신 처리
  - HandStack의 거래(Transaction) 과정 이해

---

## 왜 게시판 프로젝트인가? (2/2)

<!-- _class: reference-page -->



- 데이터베이스 처리
  - 계약(Contracts) 기반 데이터 상호작용 방법 학습

---

## 개발 보조 도구: 생성형 AI

이 프로젝트에서는 Google Gemini을 참고 자료로 활용합니다.

https://gemini.google.com/app

- 요구사항·DDL·CRUD의 초안을 요청하고 실행 전 사람이 검토합니다.
- 실제 개인정보·비밀번호·운영 데이터를 입력하지 않습니다.
- 다른 도구를 사용해도 같은 입력과 검증 기준을 적용합니다.

- 핵심 요구사항

## 화면과 기능 설계하기

사용자 스토리를 기반으로 필요한 화면과 기능을 구체화합니다.

- 게시글 목록 화면 (BOD010)
  - 조회 필터, 목록 정렬, 신규 등록/상세 조회 화면 호출
- 신규 게시글 등록 화면 (BOD011)
  - 위지윅 에디터, 제목/본문/작성자 입력
- 기존 게시글 편집 및 삭제 화면 (BOD012)
  - 게시글 정보 조회, 편집, 삭제 기능

HandStack에서 기본 제공하는 기능들로 대부분 개발이 가능합니다.

- 작업 항목 ID 분류

  - `BOD012`: 게시글 편집 및 삭제

## 4단계: 데이터베이스 설계

HandStack은 SQL Server, Oracle, MySQL/MariaDB, PostgreSQL, SQLite 등 다양한 데이터베이스를 지원합니다.
게시판 프로젝트에서는 별도 서버 설치 없이 바로 시작할 수 있는 SQLite를 사용합니다.

- Gemini 에게 테이블 설계 요청하기

> 간단한 분류 게시판 데이터베이스 테이블 정보 (컬럼명, 데이터 타입, 설명)를 SQLite 기준으로 MarkDown 문법으로 만들어줘. 그리고 실행 결과에서 테이블을 생성 하는 ddl 문법에서 ID를 자동 증가 키 컬럼으로 구성하고 기존 테이블이 없으면 CREATE 하는 예제를 알려줘

## Gemini 의 답변: 테이블 DDL

SQLite 기준으로 분류 게시판 데이터베이스 테이블을 만들었습니다.

| 컬럼명 | 데이터 타입 | 설명 |
|---|---|---|
| ID | INTEGER | 게시글의 고유 번호 (기본 키) |
| Category | TEXT | 게시글의 카테고리 |
| Title | TEXT | 게시글의 제목 |
| Content | TEXT | 게시글의 내용 |
| Author | TEXT | 게시글 작성자의 이름 |
| DatePosted | TEXT | 게시글이 작성된 날짜와 시간 |

## 쿼리 적용 (dbclient 모듈)

Gemini 이 생성한 쿼리를 HandStack의 계약(Contract) 파일에 적용합니다.

- 기능 ID 규칙
  - 기능(1) + 명령구분(1) + 순번(2) = 4자리 ID (예: `LD01`: List + Database + 01)
  - 명령구분: `D`(Database), `F`(Function), `A`(API), `T`(Task)
  - 기능: `I`(Insert), `U`(Update), `D`(Delete), `G`(Get), `L`(List), `M`(Modify)

- 이 규칙은 프로젝트의 모든 모듈에 동일하게 적용되어 일관성을 유지합니다.

---

## `dbclient` 계약 파일 예시: BOD010.xml (1/3)

<!-- _class: reference-page -->

이를 통해 복잡한 쿼리 튜닝과 소스 버전 관리가 용이합니다.

## `dbclient` 계약 파일 예시: BOD010.xml (2/3)

<!-- _class: reference-page -->



```xml
<!-- contracts/dbclient/HDS/BOD/BOD010.xml -->
<mapper xmlns="contract.xsd">
    <header>
        <application>HDS</application>
        <project>BOD</project>
        <transaction>BOD010</transaction>
        <datasource>DB01</datasource>
    </header>
    <commands>
        <statement id="LD01" desc="분류, 기간, 제목을 기준으로 게시글 조회">
            <![CDATA[
SELECT B.ID, B.Category, B.Title, B.Author, B.DatePosted, '확인' AS EditPost
FROM Board B
WHERE B.DatePosted BETWEEN @StartDate AND DATEADD(day, 1, @EndDate)
```
