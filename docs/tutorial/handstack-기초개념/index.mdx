# 01. HandStack 기초 개념

첫 조회에서 본 화면·거래·SQL의 역할을 구분합니다. 아직 실행하지 않았다면 [게시판 첫 조회](/docs/tutorial/첫-조회)부터 진행하세요.

<span id="이-주제를-배우면" />

## 선수 지식

- 웹 화면과 데이터베이스가 있다는 정도의 개념
- SQL `SELECT` 문을 읽을 수 있는 수준
- JavaScript를 읽을 수 있는 수준 (쓰지 못해도 됩니다)

## 완료 조건

- [ ] `ack` / 모듈 / 계약 / 화면을 각각 한 문장으로 설명했습니다.
- [ ] 조회 요청이 지나는 경로를 순서대로 적었습니다.
- [ ] 계약·화면 파일(`.xml`, `.json`/`.txn`, `.fnc`/함수 소스, `.html`/`.js`)와 담당 모듈을 짝지었습니다.
- [ ] 실제 예제 프로젝트에서 화면·계약 파일을 직접 찾아 열었습니다.
