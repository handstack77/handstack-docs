# 01. HandStack 기초 개념

코드를 쓰기 전에, HandStack이 무엇을 대신 해 주는 도구인지부터 이해합니다.

## 이 주제를 배우면

"화면에서 조회 버튼을 눌렀는데 데이터가 안 나온다"는 상황에서 **어디를 봐야 하는지** 스스로 판단할 수 있게 됩니다. 화면인지, 거래인지, SQL인지, 서버인지 구분하는 지도를 이 주제에서 만듭니다.

## 선수 지식

- 웹 화면과 데이터베이스가 있다는 정도의 개념
- SQL `SELECT` 문을 읽을 수 있는 수준
- JavaScript를 읽을 수 있는 수준 (쓰지 못해도 됩니다)

## 학습 목표

- `ack`, 모듈, 계약, 화면이 각각 무슨 역할인지 한 문장으로 설명합니다.
- 화면에서 시작한 요청이 데이터베이스까지 가는 경로를 그림 없이 말로 설명합니다.
- `.txn`, `.xml`, `.json` 같은 계약 파일을 보고 어떤 일을 하는 파일인지 압니다.
- HandStack이 잘 맞는 상황과 그렇지 않은 상황을 구분합니다.

## 완료 조건

- [ ] `ack` / 모듈 / 계약 / 화면을 각각 한 문장으로 설명했습니다.
- [ ] 조회 요청이 지나는 경로를 순서대로 적었습니다.
- [ ] 5개 계약 확장자(`.xml`, `.json`, `.fnc`/함수 소스, `.html`/`.js`)와 담당 모듈을 짝지었습니다.
- [ ] 실제 예제 프로젝트에서 화면·계약 파일을 직접 찾아 열었습니다.
