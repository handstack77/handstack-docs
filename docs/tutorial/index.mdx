# 따라 만들기

완성된 게시판을 먼저 실행하고, 작은 변경을 거쳐 직접 구현합니다. HTML·JavaScript·SQL 기초가 필요하며, 환경이 없다면 [내 PC에서 실행하기](/docs/startup/빠른-시작)를 먼저 마치세요.

## 첫 학습 경로

| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 실행 | [게시판 첫 조회](/docs/tutorial/첫-조회) | 목록과 검색 결과 확인 |
| 이해·수정 | [조회 조건 바꾸기](/docs/tutorial/조회-조건-바꾸기) | 입력 요소를 수정하고 요청·결과의 관계 설명 |
| 구현 준비 | [프로젝트 준비](/docs/tutorial/프로젝트와-개발서버/) → [DB 준비](/docs/tutorial/도메인모델과-데이터베이스/) | 파일 위치와 실제 연결 DB 확인 |
| 화면 구현 | [화면 작성](/docs/tutorial/화면저작/) → [이벤트 연결](/docs/tutorial/화면동작과-거래연결/) | 입력과 버튼을 거래에 연결 |
| 서버 연결 | [SQL 계약](/docs/tutorial/dbclient-SQL계약/) → [거래 계약](/docs/tutorial/transact-거래계약/) | 조회·저장 왕복 확인 |
| 진단 | [테스트와 디버깅](/docs/tutorial/테스트와-디버깅/) | 실패한 단계와 확인할 파일 설명 |

처음 두 단계는 완성 예제를 사용합니다. 직접 구현하는 단계에서는 **프로젝트·DB·화면·이벤트·SQL·거래 계약**을 모두 준비해야 합니다. 일부 파일만 작성한 상태와 실제 조회 성공을 구분하세요.

## 스스로 확인하기 {#진도-체크리스트}

- 제목 또는 분류 조건을 바꾸고 결과 차이를 설명할 수 있나요?
- 새로운 조회 기능을 만들 때 수정할 HTML·JS·JSON·XML 파일을 찾을 수 있나요?
- 응답에는 데이터가 있는데 목록이 비었다면 어떤 매핑을 확인해야 하나요?

막힌 부분만 [작업별 가이드](/docs/guides/)에서 다시 수행하세요. 정확한 API와 설정은 [레퍼런스](/docs/reference/)에서 찾습니다.
