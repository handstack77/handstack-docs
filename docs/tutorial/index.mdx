# 학습 트랙

HandStack을 처음 사용하는 개발자가 혼자서도 순서대로 익힐 수 있는 자습 코스입니다. "이 기능이 무엇을 하는가"를 정리한 [참고하기](/docs/category/환경설정) 문서와 달리, 이 트랙은 "**왜 필요한지 알고, 직접 만들어 보고, 운영까지 넘길 수 있게**" 순서를 잡아 주는 학습서입니다.

12개 주제는 하나의 게시판 프로젝트(모듈 `BOD`, 화면 `BOD010`/`BOD011`/`BOD012`)를 3~8주제에 걸쳐 계속 키워 나가는 방식으로 이어집니다. 각 주제는 내용에 맞는 개념·이해·계획·설계·실습·구축·테스트·유지보수 흐름으로 구성되며, 모든 주제가 같은 절 이름을 갖지는 않습니다.

| 나는 | 이 순서로 | 완료 기준 |

| 화면·거래를 만드는 신규 개발자 | 01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09 → 10 → 11 → 12 | 게시판 CRUD·별도 환경 검증까지 완료 |
| 화면/기능 개발자로 빠르게 실무에 투입되어야 하는 사람 | 01 → 03 → 05 → 06 → 07 → 08 | 화면 하나의 조회·저장 왕복 성공 |
| 시스템을 운영·인수인계 받는 담당자 | 01 → 02 → 03 → 11 → 12 → 10 | 기동·접근·복원·조사 재현 |
| 당장 전체 코드부터 보고 싶은 사람 | [게시판 프로젝트 시작하기](/docs/startup/handsonlab/게시판-프로젝트-시작하기) | 요약본으로 큰 그림 파악 |

## 실습이 이어지는 방식

주제 03부터 08까지는 하나의 게시판 프로젝트를 계속 키워 나갑니다. 05·06주제에서 화면과 호출을 준비해도 실제 조회·저장의 전체 성공은 07·08주제의 계약을 완성한 뒤 확인합니다.

| 화면·계약 | 하는 일 | 처음 만드는 주제 |
|---|---|---|
| 모듈 `BOD`, 프로그램 ID `HDS` | 프로젝트 골격과 개발 서버 | 03 |
| `Board` 테이블 | 게시글 데이터 구조 | 04 |
| `BOD010` | 게시글 목록·검색 화면 | 05 |
| `BOD011` | 게시글 등록 화면 | 05 · 06 |
| `BOD012` | 게시글 상세·수정·삭제 화면 | 05 · 06 |
| `BOD010.xml`, `BOD011.xml`, `BOD012.xml` | 조회·저장 SQL | 07 |
| `BOD010.json`, `BOD011.json`, `BOD012.json` | 화면과 SQL을 잇는 거래 | 08 |

전체 완성 코드는 [게시판 프로젝트 시작하기](/docs/startup/handsonlab/게시판-프로젝트-시작하기)와 [GitHub 데모 소스](https://github.com/handstack77/handstack/tree/master/2.Modules/wwwroot/Contracts)에서 한 번에 확인할 수 있습니다.
