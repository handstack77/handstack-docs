# 03. 프로젝트와 개발 서버

기존 예제를 실행한 다음, 별도의 실습 복사본에서 게시판(`BOD`)을 직접 구성합니다. 프로젝트 파일을 준비하고 `ack` 개발 서버의 정상 기동을 확인합니다.

<span id="이-주제를-배우면" />

## 선수 지식

- [02. 프로젝트 구조와 파일 작업](/docs/tutorial/프로젝트구조와-파일작업/) 완료
- [빠른 시작](/docs/startup/빠른-시작)에서 안내하는 ack 실행 환경 준비 완료

<span id="학습-목표" />

## 학습 경로

| 순서 | 문서 | 완료 후 남길 결과 |
|---|---|---|
| 1 | [프로젝트와 서버 개념](/docs/tutorial/프로젝트와-개발서버/프로젝트와-서버-개념) | ack, 프로그램 ID, 프로젝트 ID의 관계를 설명한다 |
| 2 | [새 프로젝트 만들기](/docs/tutorial/프로젝트와-개발서버/새-프로젝트-만들기) | BOD 게시판 프로젝트 골격을 만들고 서버를 기동한다 |
| 3 | [환경 구성과 기동 확인](/docs/tutorial/프로젝트와-개발서버/환경-구성과-기동확인) | 환경 프리셋을 구분하고 정상 기동 증거를 남긴다 |

## 실습에서 사용할 값

| 항목 | 값 |
|---|---|
| 프로그램 ID(ApplicationID) | `HDS` |
| 프로젝트 ID(ProjectID) | `BOD` (게시판) |
| 화면 | `BOD010`(목록), `BOD011`(등록), `BOD012`(상세/수정/삭제) |
| 데이터베이스 | SQLite (실습용 `DB01` 연결의 실제 파일, [확인 방법](/docs/tutorial/도메인모델과-데이터베이스/데이터베이스-연결과-검증)) |

## 완료 조건

- [ ] `handstack create` 또는 수동 복사로 `BOD` 프로젝트 디렉토리 골격을 만들었습니다.
- [ ] `ack`를 실행하고 `http://localhost:8421/checkup/account/signin.html`에 접속했습니다.
- [ ] 개발/검증/운영 설정 프리셋의 차이를 한 문장으로 설명했습니다.
