# 09. 확장 모듈 (function·command·repository)

SQL만으로 처리하기 어려운 로직을 위한 function, 파일 업로드/다운로드를 위한 repository 등 확장 모듈을 다루고 모듈 의존성을 관리하는 방법을 배웁니다.

## 이 주제를 배우면

거래 계약의 `CommandType`을 `F`(function)로 바꿔 서버 함수를 호출하고, 파일 첨부 기능처럼 SQL만으로 안 되는 요구사항을 어느 모듈로 풀어야 할지 판단할 수 있게 됩니다.

## 선수 지식

- [08. transact 거래 계약](/docs/tutorial/transact-거래계약/) 완료

## 학습 목표

- function/repository/command/graphclient 모듈의 역할과 사용 시점을 구분합니다.
- function 모듈로 서버 함수를 작성하고 거래로 호출합니다.
- 모듈 재적재 절차와 의존성 실패 시 로그 확인 순서를 정합니다.

## 완료 조건

- [ ] function 모듈로 간단한 서버 함수를 하나 만들고 거래로 호출했습니다.
- [ ] repository 모듈로 파일 업로드가 필요한 상황과 그렇지 않은 상황을 구분했습니다.
- [ ] 확장 모듈 실패 시 우선 확인할 로그 순서를 정했습니다.
