# 서버 프로세스 관리

> [주제 목차](/docs/tutorial/모니터링과-운영인수인계/) · 이전: [로그와 관측 개념](/docs/tutorial/모니터링과-운영인수인계/로그와-관측-개념) · 다음: [인수인계 체크리스트](/docs/tutorial/모니터링과-운영인수인계/인수인계-체크리스트)

이 문서의 결과: 서버 프로세스 상태를 확인하고 재기동 절차를 수행한다.

## 프로세스 관리가 필요한 이유

운영 환경에서는 `ack` 프로세스가 죽었을 때 자동으로 재시작되고, 로그가 유실 없이 쌓이도록 프로세스 관리자를 사용하는 것이 일반적입니다. 실습 범위에서는 프로세스 상태를 육안으로 확인하는 절차부터 익힙니다.

## handstack CLI로 프로세스 확인하기

[HandStack CLI 사용법](/docs/startup/HandStack-CLI-사용법)의 `list`/`stop` 명령으로 실행 중인 `ack` 프로세스를 확인하고 종료할 수 있습니다.

```bash
# 실행 중인 ack 프로세스 목록 확인
handstack list

# 특정 프로세스 종료
handstack stop --pid=12345
```

`list` 결과에는 프로세스 ID, 시작 시간, 사용 중인 RAM, 파일 경로가 포함됩니다. 평소와 다른 값(예상보다 높은 RAM 사용량, 예상치 못한 재시작 시간)을 발견하면 조사 대상으로 표시해 둡니다.

## 실습: 의도적으로 중지하고 재기동하기

1. `handstack list`로 현재 실행 중인 프로세스를 확인합니다.
2. 실습용 프로세스를 `handstack stop --pid=<ID>`로 중지합니다.
3. 브라우저에서 화면에 접속해 서버가 응답하지 않는 것을 확인합니다.
4. [03. 프로젝트와 개발 서버](/docs/tutorial/프로젝트와-개발서버/새-프로젝트-만들기)에서 배운 방법으로 `ack`를 다시 실행합니다.
5. 다시 접속해 정상 기동을 확인합니다.

이 실습을 미리 해 두면 실제 운영에서 프로세스가 예기치 않게 멈췄을 때 당황하지 않고 같은 절차를 따를 수 있습니다.

## 성공 증거 / 실패하면

| 확인 | 성공 | 실패 시 확인할 것 |
|---|---|---|
| 프로세스 중지 확인 | 화면 접속이 응답하지 않음 | 올바른 PID를 종료했는지 |
| 재기동 확인 | 화면이 다시 정상 응답 | 포트 충돌, 설정 파일 경로 |
