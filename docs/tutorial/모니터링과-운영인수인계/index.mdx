# 12. 모니터링과 운영 인수인계

거래 이력과 서버 상태를 관측하고, 운영을 인수인계하는 방법을 배웁니다.

## 이 주제를 배우면

장애가 났을 때 어떤 로그를 어떤 순서로 보고, 다른 담당자에게 시스템을 넘길 때 무엇을 문서로 남겨야 하는지 알게 됩니다.

## 선수 지식

- [10. 테스트와 디버깅](/docs/tutorial/테스트와-디버깅/) 완료

## 학습 목표

- HandStack에서 확인해야 할 로그 종류와 GlobalID 기준 관측 방법을 설명합니다.
- 서버 프로세스 상태를 확인하고 재기동 절차를 수행합니다.
- 인수인계 체크리스트를 실습 프로젝트 기준으로 작성합니다.

## 학습 경로

| 순서 | 문서 | 완료 후 남길 결과 |
|---|---|---|
| 1 | [로그와 관측 개념](로그와-관측-개념) | 로그 종류와 GlobalID 기준 관측 방법을 설명한다 |
| 2 | [서버 프로세스 관리](서버프로세스-관리) | 프로세스 상태를 확인하고 재기동한다 |
| 3 | [인수인계 체크리스트](인수인계-체크리스트) | 인수인계 문서를 실습 프로젝트 기준으로 작성한다 |

## 완료 조건

- [ ] GlobalID로 거래 이력을 조회해 최근 요청의 성공/실패를 확인했습니다.
- [ ] 서버를 의도적으로 중지했다가 재기동하고 정상 여부를 확인했습니다.
- [ ] 인수인계 체크리스트를 실습 프로젝트 기준으로 채워 봤습니다.
