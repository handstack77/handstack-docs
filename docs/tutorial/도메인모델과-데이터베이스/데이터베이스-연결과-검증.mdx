# 데이터베이스 연결과 검증

> [주제 목차](/docs/tutorial/도메인모델과-데이터베이스/) · 이전: [게시판 Board 테이블 설계](/docs/tutorial/도메인모델과-데이터베이스/게시판-board-테이블-설계)

이 문서의 결과: SQLite에 `Board` 테이블을 만들고 조회로 데이터를 검증한다.

## 시작 조건

- [02. 게시판 Board 테이블 설계](/docs/tutorial/도메인모델과-데이터베이스/게시판-board-테이블-설계)의 DDL을 준비했습니다.
- 실습용 SQLite 파일(`board.db`)을 운영 데이터베이스와 분리했습니다.

## 초기 데이터 넣기

```sql
CREATE TABLE IF NOT EXISTS Board (
  ID INTEGER PRIMARY KEY AUTOINCREMENT,
  Category TEXT,
  Title TEXT,
  Content TEXT,
  Author TEXT,
  DatePosted TEXT
);

INSERT INTO Board (Category, Title, Content, Author, DatePosted)
VALUES ('정보', '정보 게시물 제목1', '정보 게시물 내용1', '개발자', datetime('now', 'localtime', '-1 day'));
```

## 조회로 검증하기

```sql
SELECT ID, Category, Title, Author, DatePosted
FROM Board
ORDER BY ID DESC;
```

결과에 방금 넣은 행이 보이면 성공입니다. HandStack의 dbclient 계약에서 같은 SQL을 실행하는 방법은 [07. dbclient SQL 계약](/docs/tutorial/dbclient-SQL계약/)에서 이어서 다룹니다.

## 성공 증거 / 실패하면

| 확인 | 성공 | 실패 시 확인할 것 |
|---|---|---|
| 테이블 생성 | 오류 없이 `CREATE TABLE` 완료 | 파일 경로, 쓰기 권한 |
| 데이터 조회 | 삽입한 행이 조회됨 | 오타, 트랜잭션 커밋 여부 |
