# 04. 도메인 모델과 데이터베이스

업무 데이터를 모델로 설계하고 실제 데이터베이스 테이블과 연결하는 방법을 배웁니다. 게시판 예제의 `Board` 테이블을 이 주제에서 만듭니다.

## 이 주제를 배우면

화면에 필요한 데이터를 먼저 표로 정리하고, 그 표를 실제 데이터베이스 테이블과 SQL로 옮기는 순서를 스스로 할 수 있게 됩니다.

## 선수 지식

- [03. 프로젝트와 개발 서버](/docs/tutorial/프로젝트와-개발서버/) 완료
- SQL `CREATE TABLE`, `SELECT` 문을 읽을 수 있는 수준

## 학습 목표

- 화면 요구사항에서 필요한 컬럼과 데이터 타입을 뽑아냅니다.
- SQLite 기준으로 테이블을 만들고 초기 데이터를 넣습니다.
- dbclient가 여러 데이터베이스 종류를 어떻게 같은 방식으로 다루는지 설명합니다.

## 완료 조건

- [ ] HandStack이 공식 지원하는 5개 데이터베이스를 나열했습니다.
- [ ] `Board` 테이블의 컬럼과 데이터 타입을 설계표로 정리했습니다.
- [ ] SQLite에 `Board` 테이블을 만들고 `SELECT`로 데이터를 확인했습니다.
