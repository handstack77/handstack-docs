# 06. 화면 동작과 거래 연결

화면 이벤트로 거래를 호출하고, 메뉴와 화면 이동을 구성하는 방법을 배웁니다.

## 이 주제를 배우면

버튼 클릭이 실제 서버 거래로 이어지고, 그 결과가 다시 화면에 반영되는 전체 코드를 스스로 작성할 수 있게 됩니다.

## 선수 지식

- [05. 화면 저작](/docs/tutorial/화면저작/) 완료

## 학습 목표

- 화면 업무 로직 객체(`transaction`/`hook`/`event`)의 구조를 설명합니다.
- `BOD010`/`BOD011` 이벤트에 거래 호출을 연결합니다.
- 팝업 화면 이동과 목록 갱신 흐름을 구성합니다.

## 학습 경로

| 순서 | 문서 | 완료 후 남길 결과 |
|---|---|---|
| 1 | [화면 스크립트 구조](화면-스크립트-구조) | `transaction`/`hook`/`event` 절의 역할을 설명한다 |
| 2 | [이벤트와 거래 연결](이벤트와-거래-연결) | 조회·등록 버튼에 거래 호출을 연결한다 |
| 3 | [화면 이동과 메뉴](화면이동과-메뉴) | 팝업 이동과 목록 자동 갱신을 구성한다 |

## 완료 조건

- [ ] `BOD010.js`에 목록 조회 이벤트를 연결했습니다.
- [ ] `BOD011.js`에 등록 확인 이벤트와 유효성 검사를 작성했습니다.
- [ ] 등록 완료 후 목록 화면이 자동으로 갱신되는 흐름을 만들었습니다.
