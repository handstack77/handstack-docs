# 게시판 첫 조회

완성된 게시판을 먼저 실행합니다. 이번 단계의 목표는 **목록을 조회하고 검색 조건에 따라 결과가 달라지는 것을 확인하는 것**입니다.

## 준비

[내 PC에서 실행하기](/docs/startup/빠른-시작)를 마치고 `ack`를 실행해 두세요. 예제가 포함된 HandStack 배포본과 별도의 실습 디렉터리를 사용합니다. 이 단계에서는 HTML·SQL 파일을 새로 만들지 않습니다.

## 1. 게시판 열기

브라우저에서 [게시판 예제](http://localhost:8421/view/BOD/BOD010.html)를 여세요. 서버 포트를 바꿨다면 주소도 맞춥니다.

제목, 분류, 입력기간과 조회 버튼이 있는 화면이 나타나면 화면 로딩은 성공입니다. 404라면 [파일과 리소스 확인](/docs/guides/문제-해결#화면이-비어-있거나-리소스가-404임)을 참고하세요.

## 2. 실습 데이터 준비

데이터가 이미 표시된다면 초기화하지 않고 다음 단계로 이동하세요. 빈 실습 DB라면 다음 주의 사항을 읽고 **게시판 Board 테이블 초기화** 버튼으로 예제 데이터를 준비합니다.

:::warning 실습 DB에서만 초기화하세요

초기화는 기존 `Board` 게시글과 ID 순번을 삭제합니다. 업무 데이터가 있는 환경에서 누르지 마세요. 테이블이 없다는 오류가 나면 [Board 테이블 오류 해결](/docs/guides/문제-해결#board-table)을 확인합니다.

:::

## 3. 조회 결과 확인

제목을 비우고 분류를 ‘전체’로 선택한 뒤 **조회**를 누르세요. 입력기간은 예제 데이터의 작성일을 포함해야 합니다.

목록에 제목·분류·작성자가 표시되면 첫 조회가 완료된 것입니다. 초기화 없이 빈 DB를 사용했다면 빈 목록만으로 거래 성공을 단정하지 말고 응답과 서버 로그도 확인하세요.

## 4. 조건 하나 바꾸기

분류를 ‘강좌’로 바꾸고 다시 조회하세요. 표시된 행의 분류가 모두 ‘강좌’인지 확인한 뒤 ‘전체’로 되돌립니다.

이 작은 변경으로 **화면 입력값이 서버 조회 조건으로 전달된다**는 것을 확인했습니다.

## 어떤 파일이 연결됐나요?

| 역할 | BOD010 예제의 파일 |
|---|---|
| 입력과 목록 배치 | `contracts/wwwroot/HDS/BOD/BOD010.html` |
| 조회 버튼의 동작 | `contracts/wwwroot/HDS/BOD/BOD010.js` |
| 거래 ID와 입력·출력 정의 | `contracts/transact/HDS/BOD/BOD010.json` |
| 데이터베이스 조회 | `contracts/dbclient/HDS/BOD/BOD010.xml` |

배포본의 계약 복사 설정에 따라 모듈 안의 Contracts가 원본일 수 있습니다. 실제 편집 위치는 [파일 경로 레퍼런스](/docs/reference/식별자와-파일-경로)를 확인하세요.

조회 버튼은 JS의 `LD01`을 호출하고, `transact`가 거래 계약을 찾아 `dbclient`의 SQL을 실행합니다. 돌아온 데이터는 화면의 목록에 표시됩니다.

다음 [조회 조건 바꾸기](/docs/tutorial/조회-조건-바꾸기)에서 직접 코드를 수정합니다. 전체 구현은 [게시판 상세 예제](/docs/startup/handsonlab/게시판-프로젝트-시작하기)에 있습니다.
