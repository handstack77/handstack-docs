# 프로젝트와 서버 연결하기

프로젝트는 편집할 소스이고, 개발 서버는 그 결과를 실행하는 프로그램입니다. IDE 자체의 포트와 개발 서버의 포트도 서로 구분합니다.

## 1. 새 프로젝트 만들기

**파일 > 새 프로젝트 만들기**에서 다음 예시를 입력합니다. 기존 실습 프로젝트가 있다면 생성하지 않고 2단계로 이동하세요.

| 항목 | 실습 예시 | 규칙 |
|---|---|---|
| 프로젝트명 | `idelab` | 모듈 ID. 영문 소문자로 시작하고 소문자·숫자만 사용 |
| 프로젝트 코드 | `LAB` | 업무 프로젝트 ID. 영문 대문자 3자리 |
| 설명 | IDE 사용 실습 | 화면·계약의 설명에 사용 |
| 상위 폴더 | 별도의 실습 경로 | 기존 업무 프로젝트와 분리 |

개발 서버도 필요하면 **개발 서버 > 같이 만들기**를 선택하고 프로그램명, 비어 있는 서버 폴더, 사용 가능한 포트를 지정합니다. 생성에는 IDE 실행 파일 옆의 `rdy.zip`이 필요합니다. 이 옵션을 선택하지 않으면 프로젝트만 생성합니다.

생성 후 프로젝트 폴더를 작업 영역으로 열고 `README.md`를 읽으세요. 화면·계약 파일이 생겼다는 것과 서버 실행 준비가 끝났다는 것은 다릅니다.

## 2. 기존 서버 연동하기

1. 작업 영역 툴바의 **서버 연동**을 엽니다.
2. `app` 폴더가 들어 있는 **rdy 프로그램 루트 폴더**를 선택합니다.
3. **연동하기**를 누르고 연결 상태와 하단 **서버** 로그를 확인합니다.
4. 설정의 **기본 실행 URL**이 의도한 개발 서버를 가리키는지 확인합니다.

함께 생성한 서버가 자동 연동되었다면 다시 연동할 필요는 없습니다. 연동 실패 시에는 생성된 폴더를 무작정 지우지 말고 로그와 보존된 파일을 확인하세요.

:::warning 연동은 서버 설정을 변경합니다

연동은 서버의 계약 경로와 웹 루트를 현재 작업 영역에 맞춥니다. 다른 사람이 사용하는 서버에는 적용하지 마세요. **연동해제는 연결 기록만 지우며, 바뀐 서버 설정을 원래대로 복원하지 않습니다.**

:::

## 3. 실행 준비 확인

- 모듈을 빌드한다면 `HANDSTACK_SRC`와 `HANDSTACK_HOME`을 실습용 경로로 지정합니다. 일반 도구 설치는 [필수 프로그램](/docs/startup/install/필수-프로그램-설치하기)을 참고하세요.
- 생성된 README와 실제 설정을 대조해 실행할 ack의 `AppSettings.LoadModules`와 데이터 원본을 확인합니다.
- DB 스키마는 **실제로 실행할 `.dbc` SQL**과 대조합니다. 예제 SQL에도 테이블 생성·초기 데이터 입력이 있을 수 있으므로 업무 DB를 연결하지 않습니다.

## 직접 확인

작업 영역 경로, rdy 루트, IDE 포트, 서버 포트를 각각 기록하세요. 하단 **서버**에서 정상 시작을 확인했다면 다음 단계에서 화면을 엽니다. 실패하면 [서버·미리보기 진단](../reference/문제-해결.mdx#서버와-미리보기)을 사용하세요.
