# 작업 영역 열기

IDE가 편집할 폴더를 정하고, 파일 하나를 저장해 봅니다. 실습용 폴더에 수정해도 되는 텍스트 파일을 준비하세요.

## 1. 폴더와 파일 열기

1. 왼쪽 위 **작업 영역 폴더**를 눌러 실습 폴더를 선택합니다.
2. 트리 위 경로가 선택한 폴더인지 확인합니다.
3. 왼쪽 **작업 영역**에서 파일을 열고 짧은 문장을 추가합니다.
4. **저장**을 누른 뒤 탭을 닫고 다시 열어 문장이 남아 있는지 확인합니다.

한 번에 작업 영역 하나를 엽니다. 다른 폴더로 전환하기 전에는 미저장 탭을 먼저 정리하세요. 외부 파일 열기는 가능하지만, 외부 파일 탭은 다음 실행 때 복원되지 않습니다.

## 2. 세 탭의 차이 익히기

| 왼쪽 탭 | 무엇을 찾나요? | 여는 방식 |
|---|---|---|
| 작업 영역 | 경로와 실제 파일 | 텍스트 파일은 소스 편집기로 열기 |
| 개발 | 화면·계약의 종류와 이름 | `view`는 View Designer, 계약은 전용 편집기로 열기 |
| 업무 | 모델·환경설정·운영 도구 | 업무 화면과 오른쪽 사용 가이드 열기 |

같은 계약도 **작업 영역**에서는 원본으로, **개발**에서는 폼으로 편집합니다. 전용 편집기가 열리지 않는다고 확장자를 바꿀 필요는 없습니다.

## 3. 검색 범위 바꾸기

**편집 > 찾기**로 방금 쓴 문장을 찾고, **작업영역 찾기**로 같은 문장을 검색하세요. 전자는 현재 파일, 후자는 작업 영역의 파일들을 대상으로 합니다. 전체 검색 결과는 하단 **출력**에서 확인합니다.

여러 파일을 바꾸는 명령은 먼저 찾기로 대상과 건수를 확인한 뒤 사용하세요. 변경 후에는 diff로 의도한 파일만 수정되었는지 검토합니다.

## 직접 확인

문장을 한 번 더 바꾸고 저장 전·후의 탭 표시를 비교해 보세요. **탭을 다시 열어 변경을 확인했다면 완료**입니다. 파일이 보이지 않으면 [트리 필터와 제외 규칙](../reference/문제-해결.mdx#파일이-보이지-않음)을 확인하세요.

자주 쓰는 키는 [단축키 참조](../reference/단축키.mdx)에서 찾을 수 있습니다.
