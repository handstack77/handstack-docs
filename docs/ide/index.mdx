# IDE 사용하기

HandStack IDE(`stavlo`)는 작업 영역의 소스, 화면 디자이너, 계약 편집기와 개발 서버 도구를 한곳에서 다룹니다. 먼저 파일 하나를 저장하고, 화면 → 계약 → 실행 결과를 연결하며 익혀 보세요.

아직 설치하지 않았다면 [IDE 설치하기](/ide)에서 배포 파일을 확인하세요.

## 처음이라면 이 순서로

| 단계 | 해 볼 일 | 다음 단계로 넘어갈 기준 |
|---|---|---|
| 1. [작업 영역 열기](./learn/작업영역-열기.mdx) | 파일을 고치고 저장·다시 열기 | 실제 파일에 변경이 남음 |
| 2. [프로젝트와 서버](./learn/프로젝트와-서버.mdx) | 예제 프로젝트를 만들고 개발 서버 연동 | 작업 영역·서버 경로·포트를 구분함 |
| 3. [화면 편집하기](./learn/화면-편집하기.mdx) | View Designer에서 문구 하나 변경 | 저장 후 다시 열어도 화면 구조가 유지됨 |
| 4. [계약 실행하기](./learn/계약-실행하기.mdx) | 같은 조회를 SQL·거래·화면에서 비교 | 입력값과 결과가 세 곳에서 일치함 |
| 5. [메뉴와 검증](./learn/메뉴와-검증.mdx) | 업무 메뉴 연결, 빈 결과·실패 확인 | 성공과 실패를 응답·로그로 설명함 |
| 6. [운영 인수인계](./learn/운영-인수인계.mdx) | 백업과 재현 기록 전달 | 다른 사람이 같은 결과를 확인함 |

실습에는 별도 프로젝트와 실습 DB를 사용합니다. 이 경로의 새 프로젝트 예시는 `idelab` / `LAB`입니다. [따라 만들기](/docs/tutorial/)의 게시판 예제와는 파일·DB 구조가 다르므로 두 예제의 계약을 섞지 마세요.

## 이미 사용 중이라면

- 기능 위치: [메뉴와 도구](./reference/메뉴와-도구.mdx)
- `.txn`, `.dbc`, `pageMappings`, `data-designer-*`: [파일과 저장 규칙](./reference/파일과-저장-규칙.mdx)
- 키보드 조작: [단축키](./reference/단축키.mdx)
- 포트·미리보기·설정 저장: [설정과 보안](./reference/설정과-보안.mdx)
- 증상부터 찾기: [문제 해결](./reference/문제-해결.mdx)

설계를 먼저 정리하려면 [도메인 모델링](./guides/도메인-모델링.mdx), 서버 없이 HTML 시안을 만들려면 [Tabler 웹 페이지 제작](./guides/tabler-studio.mdx)을 선택하세요.

이 문서는 IDE의 조작과 저장·실행 경계를 설명합니다. HandStack API와 모듈 옵션의 정확한 명세는 [API·설정 참조](/docs/reference/)에서 관리합니다. 문서는 2026-09-27의 소스 기준이며, 설치된 IDE 버전에 따라 메뉴가 다를 수 있습니다.
