# 설정과 보안

설정을 바꾸기 전에 **IDE 자체**, **개발 서버**, **업무 앱** 중 어느 대상을 바꾸는지 확인하세요. 운영 환경의 값을 실습 설정에 복사하지 않습니다.

## 설정을 바꿀 위치

| 바꿀 것 | 위치 | 적용·확인 |
|---|---|---|
| 테마·글자·편집기·단축키 | 도구 > 환경설정 | 활성 화면에서 확인 |
| IDE 포트 | 환경설정 > 프로그램 > stavlo IDE 포트 | 관련 설정 갱신 후 IDE 재시작 |
| 개발 서버 연결 | 작업 영역 > 서버 연동 | rdy 루트·로그·실제 요청 확인 |
| 기본 실행 URL·브라우저 | 환경설정의 미리보기·웹 브라우저 연동 | 실제 열린 주소 확인 |
| 모듈 설정 원본 | 업무 > 환경설정 > 모듈 관리 > module.json 설정 | 현재 선택 경로와 버전 확인 |
| 환경 프리셋 | 업무 > 환경설정 > 프로그램 > 환경별 Settings 관리 | 실행 환경에 적용했는지 별도 확인 |

IDE 포트의 기준은 IDE `Bootstraping/appsettings.json`의 `AppSettings.ServerPort`입니다. 기본 예시 숫자를 불변값으로 사용하지 마세요. 포트 변경은 IDE 기능을 이용하며 모듈 URL·CSP를 일부만 수동 변경하지 않습니다.

## 미리보기 URL

주소는 기본 실행 URL과 `wwwroot` 이후 경로로 구성됩니다. 예시 파일 `wwwroot/idelab/view/HDS/LAB/LAB010.html`의 경로 부분은 `/idelab/view/HDS/LAB/LAB010.html`입니다.

IDE 자체 URL을 사용하면 IDE가 작업 영역 정적 파일을 제공할 수 있습니다. 다른 서버 URL이면 **그 서버가 같은 경로의 파일을 제공해야** 합니다. 개발 서버 연동 후에는 선택한 서버 URL로 바뀌므로 이전 주소를 그대로 재사용하지 마세요.

## 환경 프리셋과 실제 설정

환경별 Settings 화면은 루트의 `ack.{환경}.json`과 `modules`·`modulesettings`·`synconfigs`·`nodeconfigs`의 해당 환경 파일을 묶어 보여 줍니다. 환경 추가는 세트 복제이므로 주소·계정·키를 다시 확인합니다.

프리셋을 저장한 것과 실행 서버에 적용한 것은 다릅니다. 화면에 안내되는 적용 대상·명령을 검토하고 검증 환경에서 대표 거래를 실행하세요. 명령 전체 옵션은 [HandStack CLI](/docs/startup/HandStack-CLI-사용법)에서 확인합니다.

## 개발자 도구의 표시 조건

| 기능 | 조건 |
|---|---|
| 도구 > DevTools 열기, 브라우저 기본 컨텍스트 메뉴 | `AppSettings.IsDeveloperMode=true` |
| 하단 개발자 도구·API 테스트 | Debug 빌드에 디버거가 연결된 경우 |

:::warning 개발자 모드는 보안 경계도 바꿉니다

`IsDeveloperMode=true`는 DevTools 표시뿐 아니라 로컬 요청의 접근 토큰 검사도 건너뜁니다. 접속 오류를 해결하려고 무조건 켜지 마세요. 배포용 실행에서는 `false`를 유지하고 인증·호스트 상태를 진단합니다.

:::

## 키와 AI 입력

`AuthorizationKey`, `HostAccessID`, DB 연결 문자열, LLM 키는 서로 용도가 다릅니다. 문서·로그·화면 공유에 값을 남기지 마세요. AI 서비스 설정에서 공급자·모델을 고르기 전에 소스·개인정보를 해당 서비스로 전송해도 되는지 확인합니다. 생성한 SQL·HTML은 검토 후 적용합니다.
