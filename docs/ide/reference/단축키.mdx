# 단축키와 편집 문맥

아래는 Windows 기본 키입니다. 변경한 키는 **도구 > 환경설정 > 단축키**에서 확인하세요. macOS·Linux에서 같은 키가 작동한다고 가정하지 말고 설치본의 메뉴와 설정을 확인합니다.

## 소스 편집과 탐색

| 작업 | 기본 키 |
|---|---|
| 저장 / 모두 저장 | `Ctrl+S` / `Ctrl+Shift+S` |
| 모두 닫기 | `Ctrl+Alt+W` |
| 실행 취소 / 다시 실행 | `Ctrl+Z` / `Ctrl+Y` |
| 현재 파일 찾기 / 바꾸기 | `Ctrl+F` / `Ctrl+H` |
| 작업 영역 찾기 / 바꾸기 | `Ctrl+Shift+F` / `Ctrl+Shift+H` |
| 현재 문서 포맷 | `Shift+Alt+F` |
| 별도 코드 서식 도구 | `Ctrl+Alt+B` |
| 자동완성 목록 | `Ctrl+Space` |
| 시스템 터미널 | `Ctrl+Alt+Space` |
| 왼쪽 / 오른쪽 패널 토글 | `Ctrl+Alt+Left Arrow` / `Ctrl+Alt+Right Arrow` |

소스 편집 단축키는 해당 편집기에 포커스를 두고 사용합니다. 전용 화면·입력란·캔버스가 활성화되면 화면별 처리가 우선할 수 있습니다. 키가 듣지 않으면 반복해서 누르지 말고 현재 화면의 저장·실행 버튼으로 확인하세요.

## HandStack 코드 탐색

`view` 경로의 HTML에는 `syn-datafield`, `syn-options`, `syn-events` 자동완성이, JS에는 `syn.*`와 화면 객체의 자동완성이 제공됩니다. View Designer의 스크립트·소스보기에서도 사용할 수 있습니다.

| 기능 | 키·방법 | 범위 |
|---|---|---|
| 정의로 이동 | 편집기 메뉴 또는 `F12` | 화면 객체의 실제 선언, 라이브러리 API의 요약 선언 |
| 참조 찾기 | `Shift+F12` | 같은 화면 스크립트의 호출·선언 |
| 문자열 거래 ID 추적 | 오른쪽 연관 계약 찾기 | 저장된 화면·거래·실행 계약 |

`F12`는 개발자 모드에서 DevTools 키로도 쓰입니다. 혼동되면 편집기 우클릭 메뉴의 **Go to Definition**을 사용하세요. API 정의로 이동한 화면이 라이브러리 구현 전체 소스는 아닙니다.

## 디버그

| 작업 | 기본 키 |
|---|---|
| 시작·계속 / 디버그 없이 실행 | `F5` / `Ctrl+F5` |
| 실행 프로세스 Attach | `Ctrl+Alt+P` |
| 일시 중지 / 중지 | `Ctrl+Alt+Break` / `Shift+F5` |
| Step Over / Into / Out | `F10` / `F11` / `Shift+F11` |

디버그 키는 대상 프로젝트·실행 명령·활성 세션에 따라 동작합니다. 먼저 [바이너리와 PDB 조건](./문제-해결.mdx#중단점이-잡히지-않음)을 확인하세요.

## 캔버스 주의

복사·붙여넣기·삭제는 선택한 블록을 바꿀 수 있습니다. 입력란 안에서는 텍스트 편집이 우선합니다. View Designer의 Position Layout은 스냅 상태에 따라 이동량이 달라지며 Studio와 같은 수치를 전제하지 마세요. 실행 전 선택 요소와 현재 레이아웃을 확인합니다.
