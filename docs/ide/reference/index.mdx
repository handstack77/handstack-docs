# IDE 빠른 참조

조작 순서를 배우려면 [하나씩 익히기](../learn/작업영역-열기.mdx), 정확한 이름이나 규칙을 찾으려면 아래 링크를 사용하세요.

## 이름으로 찾기

| 검색어 | 대표 문서 |
|---|---|
| 작업 영역, 개발, 업무, 연관 계약 찾기 | [메뉴와 도구](./메뉴와-도구.mdx) |
| `.txn`, `.dbc`, `.bas`, `.fnc`, `.cyp`, `.pmt`, `.rpo` | [계약 확장자](./파일과-저장-규칙.mdx#계약-확장자) |
| `ModuleID`, 프로젝트 코드, `Contracts`, `wwwroot` | [프로젝트 경로](./파일과-저장-규칙.mdx#프로젝트-경로) |
| `stavlo`, `stavlo.csproj`, `Stavlo`, 패키지 ID, IDE 실행 파일 | [IDE 자체 프로젝트](./파일과-저장-규칙.mdx#ide-host-project) |
| `pageMappings`, `data-designer-*`, `data-studio-props` | [화면 원본](./파일과-저장-규칙.mdx#화면-원본) |
| `menus.json`, `DirectoryID`, `ItemID`, `FnSearch` | [메뉴 연결](./파일과-저장-규칙.mdx#메뉴-연결) |
| `.project.json`, IndexedDB, `data`, 백업 | [백업 대상](./파일과-저장-규칙.mdx#백업-대상) |
| `Ctrl+S`, `F12`, `F5`, 포맷 | [단축키와 포커스](./단축키.mdx) |
| `ServerPort`, 미리보기 URL, Settings, `IsDeveloperMode` | [설정과 보안](./설정과-보안.mdx) |
| `GlobalID`, HTTP 200인데 실패, PDB | [문제 해결](./문제-해결.mdx) |
