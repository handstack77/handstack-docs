# 메뉴와 도구

파일을 찾는 곳은 **작업 영역**, 계약 종류를 찾는 곳은 **개발**, 설정·모델·운영 기능을 찾는 곳은 **업무**입니다.

## 자주 하는 작업

| 작업 | 위치 | 범위·주의 |
|---|---|---|
| 폴더 열기 | 왼쪽 위 작업 영역 폴더 | 현재 작업 영역 전환 |
| 프로젝트 생성 | 파일 > 새 프로젝트 만들기 | 모듈 소스와 예제 생성 |
| rdy 배포 | 파일 > 개발 서버 만들기 | 비어 있는 서버 폴더 필요 |
| 서버 연결 | 작업 영역 툴바 > 서버 연동 | 연결 대상의 설정 변경 |
| 원본 편집 | 작업 영역 > 파일 선택 | 텍스트 소스 편집기 |
| 화면·계약 폼 편집 | 개발 > 유형 필터 > 항목 선택 | 전용 저작 화면 |
| 전체 파일 검색 | 편집 > 작업영역 찾기 | 결과는 하단 출력 |
| 화면 실행 | view 항목·탭 우클릭 > 웹 브라우저로 열기 | 서버 연동과 URL 확인 |
| 업무 메뉴 편집 | 도구 > 유틸리티 > 메뉴 정보 관리 | 프로젝트의 `menus.json` |
| IDE 표시·키·포트 설정 | 도구 > 환경설정 | 서버 설정과 구분 |

## 오른쪽 패널

| 기능 | 나타나는 문맥 | 활용 |
|---|---|---|
| 심볼 아웃라인 | 일반 소스 탭 | 함수·클래스·HTML ID로 이동 |
| 연관 계약 찾기 | 계약, View Designer, `view` 하위 JS | 호출하는 계약·호출받는 계약 추적 |
| 화면 정보 | HTML·HTM 소스 | `syn_*` 메타데이터 편집 후 파일 저장 |
| 실행 이력 | DB·거래 클라이언트 | 이전 SQL·요청 복원 |
| 업무 화면 가이드 | 업무 화면 | 현재 화면의 항목·사용법·주의 확인 |

**연관 계약 찾기**는 저장된 파일을 읽습니다. 문자열 기능 ID는 일반 ‘정의로 이동’ 대신 이 도구로 추적하세요. 작업 영역에서 클릭하면 소스로, 개발 탭에서 클릭하면 전용 편집기로 이어집니다.

## 개발과 운영 도구

| 도구 | 메뉴 경로 | 쓰는 때 |
|---|---|---|
| Tabler 웹 페이지 제작 | 도구 > 개발 도구 | 서버 없이 HTML 시안 작성 |
| DB 클라이언트 | 도구 > 개발 도구 | 연결·메타데이터·SQL 확인 |
| 거래 클라이언트 | 도구 > 개발 도구 | 모듈 실행 요청의 URL·헤더·본문 시험 |
| 데이터 원본·거래 라우팅 | 업무 > 환경설정 > 프로그램 | 환경의 연결·실행 대상 확인 |
| 환경별 Settings 관리 | 업무 > 환경설정 > 프로그램 | 환경 프리셋 비교·복제·편집 |
| module.json 설정 | 업무 > 환경설정 > 모듈 관리 | 모듈 설정 원본 편집 |
| 모듈별 API 콘솔 | 업무 > 환경설정 > 모듈 관리 | 실행 서버의 계약·캐시 등 조회·관리 |
| 엔티티·앱 데이터베이스 | 업무 > 도메인 모델 > 메타 정보 관리 | 모델 작성·ERD 확인 |
| SDLC 도구 | 업무 > 도메인 모델 > 기획·계획 / 분석 / 설계 / 구현 | 설계와 결정 근거 작성 |
| 거래 이력정보·ack 서버 정보 | 업무 > 프로젝트 관리 > 모니터링 | 요청 실패·서버 상태 추적 |

계약 편집기의 **거래 실행**은 작성 중인 계약을 시험하고, **거래 클라이언트**는 HTTP 요청을 직접 구성합니다. **모듈 API 콘솔**은 실행 서버의 관리 상태를 다룹니다. 이름이 비슷해도 변경 대상이 다릅니다.

삭제·캐시 제거·재적재·DB 변경은 실제 데이터나 실행 상태에 영향을 줍니다. 조회로 대상을 확인하고 백업·복구 수단을 마련한 뒤 수행하세요. repository 화면의 오른쪽 파일 도구도 실제 저장소를 변경합니다.

## 하단 패널

- **서버**: 연동 개발 서버의 시작·중지·로그
- **콘솔**: IDE·웹 UI 동작 오류
- **출력**: 검색·바꾸기 등 작업 결과
- **터미널**: Photino 앱에서 경로별 셸 실행
- **디버그**: ack 시작·Attach·중단점·변수 확인

일부 하단 개발 도구는 Debug 빌드에 디버거가 연결된 경우에만 보입니다. 도구 메뉴의 DevTools 표시 조건과는 다릅니다. [설정과 보안](./설정과-보안.mdx#개발자-도구의-표시-조건)을 확인하세요.
