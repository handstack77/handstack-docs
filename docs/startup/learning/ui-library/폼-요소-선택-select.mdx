# 선택(Select)

분류: 폼 요소

## 소스
```html
<div class="mb-3">
    <div class="form-label">선택</div>
    <select class="form-select">
        <option value="1">옵션 1</option>
        <option value="2">옵션 2</option>
        <option value="3">옵션 3</option>
    </select>
</div>

<div class="mb-3">
    <div class="form-label">다중 선택</div>
    <select class="form-select" multiple="">
        <option value="1">옵션 1</option>
        <option value="2">옵션 2</option>
        <option value="3">옵션 3</option>
    </select>
</div>
```

## 사용된 주요 클래스
`form-label`, `form-select`, `mb-3`

## 실전 예제 페이지
HandStack 웹 호스트(`wwwroot` 모듈)를 기동한 뒤 `/sample/ui-library/폼-요소-선택-select.html` 경로에서 렌더링 결과를 확인할 수 있습니다.
