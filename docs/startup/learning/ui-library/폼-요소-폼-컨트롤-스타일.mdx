# 폼 컨트롤 스타일

분류: 폼 요소

## 소스
```html
<div class="mb-3">
    <label class="form-label">둥근 폼 컨트롤</label>
    <input type="text" class="form-control form-control-rounded mb-2" name="Form control rounded" placeholder="텍스트..">
    <div class="input-icon">
        <input type="text" class="form-control form-control-rounded" placeholder="검색…">
        <span class="input-icon-addon">
            <i class="f:20 ti ti-search"></i>
        </span>
    </div>
</div>

<div class="mb-3">
    <label class="form-label">플러시 폼 컨트롤</label>
    <input type="text" class="form-control form-control-flush" name="Form control flush" placeholder="텍스트..">
</div>
```

## 사용된 주요 클래스
`f:20`, `form-control`, `form-control-flush`, `form-control-rounded`, `form-label`, `input-icon`, `input-icon-addon`, `mb-2`, `mb-3`, `ti`, `ti-search`

## 실전 예제 페이지
HandStack 웹 호스트(`wwwroot` 모듈)를 기동한 뒤 `/sample/ui-library/폼-요소-폼-컨트롤-스타일.html` 경로에서 렌더링 결과를 확인할 수 있습니다.
