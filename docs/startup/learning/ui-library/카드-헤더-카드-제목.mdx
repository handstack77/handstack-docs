# 카드 제목

분류: 카드 헤더

## 소스
```html
<div class="card overflow-auto">
    <div class="card-header">
        <h3 class="card-title">카드 제목</h3>
        <div class="card-actions">
            <a href="#" class="btn">
                <i class="f:20 ti ti-phone"></i>
                전화
            </a>
            <a href="#" class="btn">
                <i class="f:20 ti ti-mail"></i>
                이메일
            </a>
        </div>
    </div>
</div>
```

## 사용된 주요 클래스
`btn`, `card`, `card-actions`, `card-header`, `card-title`, `f:20`, `overflow-auto`, `ti`, `ti-mail`, `ti-phone`

## 실전 예제 페이지
HandStack 웹 호스트(`wwwroot` 모듈)를 기동한 뒤 `/sample/ui-library/카드-헤더-카드-제목.html` 경로에서 렌더링 결과를 확인할 수 있습니다.
