# UI 라이브러리 예제 소개

HandStack 화면(Tabler 기반 UI)에서 자주 쓰는 레이아웃·컴포넌트 마크업을 분류별로 모은 참고 예제입니다.
마크업은 Tabler(`tabler-core`) 컴포넌트 클래스와 master-css(`f:`, `b:`, `m-`, `p-` 등 속성형 유틸리티) 표기를 함께 사용합니다.

각 문서는 소스 마크업과 함께 HandStack 웹 호스트의 `/sample/ui-library/<파일명>.html` 미리보기 페이지를 안내합니다.
원본 소스는 저장소의 `2.Modules/wwwroot/wwwroot/sample/ui-library`에 있으며, qcn.winform view-designer "UI 라이브러리" 팝업 카탈로그에서 옮긴 것입니다.
