# 사각 버튼

분류: 버튼

버튼의 둥근 모서리(border-radius)를 없애 **완전한 사각형**으로 만드는 수식자 클래스입니다. `btn` 계열 클래스에 `btn-square`를 추가하면 되며, 아이콘 버튼을 격자 형태로 촘촘히 배치하거나 각진 UI 톤을 유지해야 하는 화면에 사용합니다.

## 소스
```html
<div class="card overflow-auto">
    <div class="card-status-top bg-dark-overlay"></div>
    <div class="card-header">
        <h3 class="card-title">사각 버튼</h3>
    </div>
    <div class="card-body">
        <p>
            사각 버튼을 사용하려면 <code>.btn-square</code> 클래스를 사용하세요.
        </p>
        <div class="row g-2 align-items-center">
            <div class="col-12 col-xl-2 font-weight-semibold">일반</div>
            <div class="col-6 col-sm-4 col-md-2 col-xl py-3">
                <a href="#" class="btn btn-primary btn-square w-100">
                    프라이머리
                </a>
            </div>
            <div class="col-6 col-sm-4 col-md-2 col-xl py-3">
                <a href="#" class="btn btn-secondary btn-square w-100">
                    세컨더리
                </a>
            </div>
            <div class="col-6 col-sm-4 col-md-2 col-xl py-3">
                <a href="#" class="btn btn-success btn-square w-100">
                    성공
                </a>
            </div>
            <div class="col-6 col-sm-4 col-md-2 col-xl py-3">
                <a href="#" class="btn btn-warning btn-square w-100">
                    경고
                </a>
            </div>
            <div class="col-6 col-sm-4 col-md-2 col-xl py-3">
                <a href="#" class="btn btn-danger btn-square w-100">
                    위험
                </a>
            </div>
            <div class="col-6 col-sm-4 col-md-2 col-xl py-3">
                <a href="#" class="btn btn-info btn-square w-100">
                    정보
                </a>
            </div>
            <div class="col-6 col-sm-4 col-md-2 col-xl py-3">
                <a href="#" class="btn btn-dark btn-square w-100">

                <a href="#" class="btn btn-light btn-square w-100">

                </a>
            </div>
        </div>
    </div>
</div>
```

## 사용된 주요 클래스

| 클래스 | 역할 |
| --- | --- |
| `btn` | 버튼의 공통 크기·여백·전환 효과를 적용하는 Bootstrap 기본 클래스 |
| `btn-primary` / `btn-secondary` / `btn-success` / `btn-warning` / `btn-danger` / `btn-info` / `btn-dark` / `btn-light` | 버튼의 시맨틱 색상(배경·테두리·글자색)을 지정 |
| `btn-square` | 버튼의 모서리 둥글기(border-radius)를 제거해 사각형으로 표시 |
| `row`, `g-2` | Bootstrap 그리드 행과 열 사이 간격(gutter) |
| `col-12`, `col-6`, `col-sm-4`, `col-md-2`, `col-xl`, `col-xl-2` | 화면 폭 구간별로 버튼 열의 너비를 다르게 지정하는 반응형 그리드 열 |
| `align-items-center` | 행(row) 안의 항목을 세로 중앙에 정렬 |
| `font-weight-semibold` | 상태 구분 라벨 글자 굵기를 semibold로 지정 |
| `py-3` | 버튼 열의 상하 여백을 지정 |
| `w-100` | 버튼 너비를 부모 열의 100%로 확장 |
| `bg-dark` | 라이트 버튼이 배경과 구분되도록 어두운 배경을 지정 |
