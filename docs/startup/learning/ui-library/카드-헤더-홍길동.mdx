# 홍길동

분류: 카드 헤더

## 소스
```html
<div class="card overflow-auto">
    <div class="card-header">
        <div>
            <div class="row align-items-center">
                <div class="col-auto">
                    <span class="avatar" style="background-image: url(../../img/avatars/000m.jpg)"></span>
                </div>
                <div class="col">
                    <div class="card-title">홍길동</div>
                    <div class="card-subtitle">UI 디자이너</div>
                </div>
            </div>
        </div>
        <div class="card-actions">
            <a href="#" class="btn">
                <i class="f:20 ti ti-phone"></i>
                전화
            </a>
            <a href="#" class="btn">
                <i class="f:20 ti ti-mail"></i>
                이메일
            </a>
        </div>
    </div>
</div>
```

> 원본 이미지 경로(`img/...`)는 참고용 표시이며 실제 이미지 파일은 포함하지 않았습니다. 미리보기 페이지에서는 자리 표시 이미지로 대체됩니다.

## 사용된 주요 클래스
`align-items-center`, `avatar`, `btn`, `card`, `card-actions`, `card-header`, `card-subtitle`, `card-title`, `col`, `col-auto`, `f:20`, `overflow-auto`, `row`, `ti`, `ti-mail`, `ti-phone`

## 실전 예제 페이지
HandStack 웹 호스트(`wwwroot` 모듈)를 기동한 뒤 `/sample/ui-library/카드-헤더-홍길동.html` 경로에서 렌더링 결과를 확인할 수 있습니다.
