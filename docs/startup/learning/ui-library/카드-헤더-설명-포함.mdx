# 설명 포함

분류: 카드 헤더

카드 제목 아래에 간단한 설명을 추가할 수 있습니다.

## 소스
```html
<div class="card overflow-auto">
    <div class="card-header">
        <div>
            <h3 class="card-title">
                설명 포함
            </h3>
            <p class="card-subtitle">
                카드 제목 아래에 간단한 설명을 추가할 수 있습니다.
            </p>
        </div>
    </div>
</div>
```

## 사용된 주요 클래스
`card`, `card-header`, `card-subtitle`, `card-title`, `overflow-auto`

## 실전 예제 페이지
HandStack 웹 호스트(`wwwroot` 모듈)를 기동한 뒤 `/sample/ui-library/카드-헤더-설명-포함.html` 경로에서 렌더링 결과를 확인할 수 있습니다.
