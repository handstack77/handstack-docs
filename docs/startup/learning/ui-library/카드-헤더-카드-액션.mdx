# 카드 액션

## 소스
```html
<div class="card overflow-auto">
    <div class="card-header">
        <h3 class="card-title">카드 액션</h3>
        <div class="card-actions btn-actions">
            <a href="#" class="btn-action">
                <i class="f:20 ti ti-refresh"></i>
            </a>
            <a href="#" class="btn-action">
                <i class="f:20 ti ti-chevron-up"></i>
            </a>
            <a href="#" class="btn-action">
                <i class="f:20 ti ti-dots-vertical"></i>
            </a>
            <a href="#" class="btn-action">
                <i class="f:20 ti ti-x"></i>
            </a>
        </div>
    </div>

```

## 사용된 주요 클래스
`btn-action`, `btn-actions`, `card`, `card-actions`, `card-header`, `card-title`, `f:20`, `overflow-auto`, `ti`, `ti-chevron-up`, `ti-dots-vertical`, `ti-refresh`, `ti-x`

## 실전 예제 페이지
