# 액션이 있는 카드

분류: 카드 헤더

## 소스
```html
<div class="card overflow-auto">
    <div class="card-header">
        <h3 class="card-title">액션이 있는 카드</h3>
        <div class="card-actions">
            <a href="#" class="btn btn-primary">
                <i class="f:20 ti ti-plus"></i>
                새로 추가
            </a>
        </div>
    </div>
</div>
```

## 사용된 주요 클래스
`btn`, `btn-primary`, `card`, `card-actions`, `card-header`, `card-title`, `f:20`, `overflow-auto`, `ti`, `ti-plus`

## 실전 예제 페이지
HandStack 웹 호스트(`wwwroot` 모듈)를 기동한 뒤 `/sample/ui-library/카드-헤더-액션이-있는-카드.html` 경로에서 렌더링 결과를 확인할 수 있습니다.
