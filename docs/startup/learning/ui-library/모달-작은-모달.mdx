# 작은 모달

분류: 모달

## 소스
```html
<a href="#" class="btn" data-bs-toggle="modal" data-bs-target="#modal-small">
    작은 모달
</a>

<div class="modal modal-blur fade" id="modal-small" tabindex="-1" role="dialog" aria-hidden="true">
    <div class="modal-dialog modal-sm modal-dialog-centered" role="document">
        <div class="modal-content">
            <div class="modal-body">
                <div class="modal-title">정말 삭제하시겠습니까?</div>
                <div>계속 진행하면 모든 개인 데이터가 손실됩니다.</div>
            </div>
            <div class="modal-footer">
                <button type="button" class="btn btn-link link-secondary me-auto" data-bs-dismiss="modal">취소</button>
                <button type="button" class="btn btn-danger" data-bs-dismiss="modal">예, 모든 데이터를 삭제합니다</button>
            </div>
        </div>
    </div>
</div>
```

## 사용된 주요 클래스
`btn`, `btn-danger`, `btn-link`, `fade`, `link-secondary`, `me-auto`, `modal`, `modal-blur`, `modal-body`, `modal-content`, `modal-dialog`, `modal-dialog-centered`, `modal-footer`, `modal-sm`, `modal-title`

## 실전 예제 페이지
HandStack 웹 호스트(`wwwroot` 모듈)를 기동한 뒤 `/sample/ui-library/모달-작은-모달.html` 경로에서 렌더링 결과를 확인할 수 있습니다.
