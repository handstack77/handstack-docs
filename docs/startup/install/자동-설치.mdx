# 개발 도구 자동 설치

도구를 개별 설치하려면 [필수 프로그램 안내](/docs/startup/install/필수-프로그램-설치하기)의 공식 링크를 사용하세요. 여러 도구를 함께 준비하려는 경우에만 아래 스크립트를 선택합니다.

이 스크립트는 **PC의 개발 도구를 설치**합니다. 배포본의 `install.bat`·`install.sh`로 **HandStack 패키지와 화면 자원을 구성**하는 단계와 다릅니다.

## 스크립트 받기

| 대상 | 파일 | 준비 사항 |
|---|---|---|
| Windows 11 x64 | [windows-bootstrapper.ps1](/install/windows-bootstrapper.ps1) | Windows PowerShell 5.1, WinGet |
| macOS 14·15·26 | [macos-bootstrapper.sh](/install/macos-bootstrapper.sh) | 현재 사용자로 실행, 스크립트 내 OS·CPU 확인 |
| Ubuntu 26.04 amd64 | [ubuntu-bootstrapper.sh](/install/ubuntu-bootstrapper.sh) | 현재 사용자로 실행, 필요한 패키지 설치 시 sudo |

기존 설치 문서의 스크립트를 별도 파일로 제공합니다. .NET SDK, Node.js, Git, curl, gulp-cli, LibMan, PowerShell과 PATH를 구성하므로 실행 전에 내용을 확인하세요. 대상 OS가 다르거나 도구 버전을 직접 관리한다면 공식 설치 방법을 사용합니다.

## 실행

내려받은 파일이 있는 디렉터리에서 실행하세요. Windows 파일은 한국어 메시지를 위해 UTF-8 BOM으로 제공합니다.

Windows PowerShell:

~~~powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\windows-bootstrapper.ps1
~~~

macOS:

~~~bash
bash ./macos-bootstrapper.sh
~~~

Ubuntu:

~~~bash
bash ./ubuntu-bootstrapper.sh
~~~

macOS·Ubuntu에서는 스크립트 전체에 `sudo`를 붙이지 마세요. 사용자 전역 도구와 PATH가 다른 계정에 설치될 수 있습니다.

## 완료 확인

새 터미널에서 [필수 도구 확인 명령](/docs/startup/install/필수-프로그램-설치하기#설치-완료-기준)을 실행하세요. 자동 설치 로그에 실패가 있으면 실패한 도구의 공식 안내에서 해결한 뒤 다시 확인합니다.

- `npm`을 찾지 못하면 Node.js 설치와 새 터미널의 PATH를 확인합니다.
- `libman`·`pwsh`를 찾지 못하면 `dotnet tool list --global`과 사용자 .NET 도구 경로를 확인합니다.
- 프록시 환경에서 실패하면 오류에 표시된 배포 사이트 접근 여부를 확인합니다.

이후 [내 PC에서 실행하기](/docs/startup/빠른-시작)에서 HandStack을 구성합니다.
