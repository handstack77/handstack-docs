# 지원 운영체제

HandStack은 Windows, Linux, macOS용으로 배포합니다. 설치할 때는 **HandStack 릴리스의 대상 OS·CPU**와 **해당 .NET 버전의 지원 범위**를 함께 확인하세요.

## 배포본 선택

[HandStack 릴리스](https://github.com/handstack77/handstack/releases/latest)의 설명과 제공 파일을 기준으로 선택합니다.

| 파일명 표기 | 의미 |
|---|---|
| `win` / `linux` / `osx` | Windows / Linux / macOS |
| `x64` | Intel·AMD 64비트 |
| `arm64` | ARM 64비트 |

현재 소스의 `ack` 대상은 `net10.0`입니다. 다른 릴리스를 사용한다면 해당 릴리스의 요구사항을 우선하세요. .NET이 특정 OS를 지원한다는 사실만으로 모든 HandStack 모듈과 네이티브 의존성의 호환성이 보장되지는 않습니다.

## 공식 지원 범위 {#net-10-지원-운영체제}

- [Windows의 .NET 지원과 설치](https://learn.microsoft.com/ko-kr/dotnet/core/install/windows)
- [macOS의 .NET 지원과 설치](https://learn.microsoft.com/ko-kr/dotnet/core/install/macos)
- [Ubuntu의 .NET 지원과 설치](https://learn.microsoft.com/ko-kr/dotnet/core/install/linux-ubuntu-install)
- [Node.js 릴리스 지원 일정](https://nodejs.org/en/about/previous-releases)

Apple Silicon에서는 배포본과 .NET의 아키텍처를 맞추세요. x64용 파일을 받았다면 네이티브 arm64 실행으로 가정하지 말고 릴리스와 공식 설치 안내를 확인합니다.

도구 선택을 마쳤다면 [필수 프로그램 안내](/docs/startup/install/필수-프로그램-설치하기)로 이동하세요.
