# 개발 환경 설정하기

서버 소스나 모듈을 수정할 때만 이 과정을 진행하세요. 화면·계약 실습은 [배포본 실행](/docs/startup/빠른-시작)으로 시작할 수 있습니다.

[필수 도구](/docs/startup/install/필수-프로그램-설치하기)와 Git을 준비합니다. 소스 빌드에는 .NET SDK 10이 필요합니다. Git 사용법은 [공식 Git 문서](https://git-scm.com/docs)를 참고하세요.

## 소스 복제 {#github-프로젝트를-cli-명령어로-복제}

쓰기 가능한 작업 디렉터리에서 실행합니다. 이미 복제했다면 다시 내려받지 말고 사용 중인 브랜치와 변경 사항을 확인하세요.

~~~bash
git clone https://github.com/handstack77/handstack.git
cd handstack
~~~

이 문서의 **소스 기본경로**는 위에서 만들어진 저장소 디렉터리입니다. 배포본의 `app` 디렉터리와 다릅니다.

## 의존성과 도구 준비 {#프로젝트-빌드-및-종속성-및-도구를-복원}

저장소 루트에서 OS에 맞는 스크립트를 실행합니다. 스크립트는 npm 패키지, 화면 자원과 .NET 도구를 구성하며 사용자 환경 변수·PATH도 변경할 수 있습니다. 기존 개발 환경에서는 먼저 내용을 확인하세요.

### Windows {#windows-운영체제에서-실행하기}

~~~powershell
.\install.bat
~~~

### macOS·Linux {#macos-linux-운영체제에서-실행하기}

~~~bash
bash ./install.sh
~~~

사용자 도구가 다른 계정에 설치되지 않도록 스크립트 전체에 `sudo`를 붙이지 않습니다. 줄바꿈 오류가 나면 파일을 LF로 저장한 뒤 다시 실행하세요.

## 빌드와 확인

설치 로그에 실패가 없는지 확인하고 [도구 확인 명령](/docs/startup/install/필수-프로그램-설치하기#설치-완료-기준)을 실행합니다. 이어서 [빌드·릴리즈·실행 절차](/docs/twelvefactor/빌드-릴리즈-실행/빌드-릴리즈-실행-절차)에서 대상 OS의 빌드 명령과 산출물 경로를 확인하세요.

빌드 스크립트는 출력 디렉터리와 계약 복사본을 갱신할 수 있습니다. 기존 실행 환경을 덮어쓰지 않도록 대상 경로와 변경 파일을 확인한 뒤 실행합니다.
