# 패키지 관리자 설치하기

패키지 관리자는 개발 도구를 명령으로 설치하거나 업데이트할 때 사용합니다. 공식 설치 프로그램을 이용한다면 이 단계를 건너뛰고 [필수 프로그램 안내](/docs/startup/install/필수-프로그램-설치하기)로 이동하세요.

## Windows: WinGet {#windows-에-winget-설치하기}

PowerShell에서 `winget --version`을 실행하세요. 버전이 표시되면 준비되어 있습니다. 명령을 찾지 못하면 [Microsoft의 WinGet 설치 안내](https://learn.microsoft.com/ko-kr/windows/package-manager/winget/)에 따라 앱 설치 관리자를 확인하세요.

설치·업데이트·검색 등 전체 명령은 같은 공식 문서에서 확인할 수 있습니다. HandStack에 필요한 도구는 [필수 프로그램 안내](/docs/startup/install/필수-프로그램-설치하기)에 정리되어 있습니다.

## macOS: Homebrew

터미널에서 `brew --version`을 실행하세요. 설치가 필요하면 [Homebrew 공식 설치 안내](https://docs.brew.sh/Installation)를 따릅니다. 설치가 끝난 뒤 공식 안내의 PATH 설정을 적용하고 새 터미널에서 다시 확인하세요.

## Linux

배포판이 제공하는 패키지 관리자를 사용합니다. Ubuntu의 .NET 설치는 [Microsoft의 Ubuntu 설치 안내](https://learn.microsoft.com/ko-kr/dotnet/core/install/linux-ubuntu-install)를 따르세요. 다른 배포판의 명령을 그대로 섞어 실행하지 마세요.

다음은 [필수 도구 확인과 설치](/docs/startup/install/필수-프로그램-설치하기)입니다.
