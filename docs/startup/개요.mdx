# HandStack 시작하기

HandStack은 HTML·JavaScript로 만든 화면과 SQL을 연결해 업무 웹 앱을 개발하는 환경입니다. 화면 파일, 거래 규칙, SQL을 각각 관리하고 `ack` 서버에서 실행합니다.

## 먼저 게시판을 실행해 보세요

HTML·JavaScript·SQL 기초를 알고 있다면 다음 순서로 시작하세요.

1. [필요한 도구 확인하기](/docs/startup/install/필수-프로그램-설치하기): 설치된 도구를 확인하고 부족한 것만 준비합니다.
2. [내 PC에서 실행하기](/docs/startup/빠른-시작): 배포본을 구성하고 서버 접속을 확인합니다.
3. [게시판 첫 조회](/docs/tutorial/첫-조회): 예제를 실행하고 검색 조건을 바꿉니다.

화면을 직접 만드는 단계는 [따라 만들기](/docs/tutorial/)에서 이어집니다. 처음부터 서버 소스를 빌드할 필요는 없습니다.

## 지금 알아둘 세 가지

| 이름 | 하는 일 |
|---|---|
| `ack` | HandStack 모듈을 실행하는 웹 서버 |
| 화면 | 사용자가 입력하고 결과를 확인하는 HTML·JavaScript 파일 |
| 계약(contracts) | 어떤 거래를 실행하고 어떤 SQL을 사용할지 정한 파일 |

게시판의 조회 버튼은 **화면 → transact(거래 연결) → dbclient(SQL 실행) → 화면에 결과 표시** 순서로 동작합니다. 자세한 [요청 흐름](/docs/tutorial/handstack-기초개념/요청흐름-이해)은 예제를 실행한 뒤 확인하세요.

## 필요한 문서 찾기

- 기능을 구현하려면 [작업별 가이드](/docs/guides/)를 확인하세요.
- API·설정·파일 규칙은 [HandStack 레퍼런스](/docs/reference/)에서 찾으세요.
- 구조와 설계 배경은 [개념 이해](/docs/reference/concept/)에서 읽으세요.
- 서버나 모듈 소스를 바꾸려면 [소스 개발 환경](/docs/startup/install/개발-환경-설정하기)을 준비하세요.

도입 배경과 조직의 역할 분담은 [도메인 주도 로우코드 거버넌스](/docs/reference/concept/domain-driven-low-code-governance), 사용 조건은 [라이선스](/docs/라이선스)에 정리되어 있습니다.
