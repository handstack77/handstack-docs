# MCP 서버 및 스킬 사용

HandStack 문서 MCP를 연결하고 스킬을 설치한 뒤, 기존 게시판의 조회 흐름을 읽고 작성자 검색 조건을 추가하는 과정을 따라 합니다. Claude Code 또는 Codex CLI 중 사용하는 도구의 실습을 선택하세요.

## 준비와 실습 범위

- 설치·로그인을 마친 Claude Code 또는 Codex CLI, PowerShell, 인터넷 연결이 필요합니다. 스킬 점검기는 Python 3.10 이상을 사용합니다.
- 문서 검색과 연결 관리는 업무 DB 없이 따라 할 수 있습니다. 게시판 변경·조회 실습은 BOD010 예제 또는 기존 조회 화면과 분리된 테스트 DB를 준비합니다.
- MCP 개념, 추가·조회·범위별 공유·설정 변경·삭제·비활성화·갱신, 스킬 설치·호출·백업·갱신·제외를 다룹니다.
- 기본 게시판 예제의 `.json/.xml` 계약과 프로젝트별 `.txn/.dbc` 계약을 구분하고, 기존 경로·확장자·입출력 계약을 보존합니다.
- 작성자 검색 HTML·SQL은 학습용 추가 예시입니다. 코드 검사와 실제 서버·브라우저·DB 검증을 나눠 확인합니다.

명령 예시는 Codex CLI 0.164.0과 Claude Code 2.1.310 기준입니다. 다른 버전에서는 해당 도구의 `mcp --help`와 공식 안내를 확인하세요.
