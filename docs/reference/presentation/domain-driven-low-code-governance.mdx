# HandStack 도메인 주도 로우코드 거버넌스

도메인 담당자가 HandStack으로 필요한 정보화 시스템을 직접 구현하고, 중앙 IT 조직은 표준·보안·품질·운영 경계를 제공하는 방법을 소개합니다.

이 발표는 다음 질문에 답합니다.

- HandStack의 로우코드는 일반적인 노코드 방식과 무엇이 다른가?
- 도메인 자율성과 중앙 IT 통제를 어떻게 함께 확보할 수 있는가?
- 개발 비용뿐 아니라 변경·연계·운영·인수인계 비용을 어떻게 줄이고 측정하는가?
- 어떤 변경은 도메인 팀이 직접 처리하고 어떤 변경은 전문 검토를 받아야 하는가?
- 작은 업무에서 시작해 조직의 정보화 역량으로 확장하려면 무엇을 표준화해야 하는가?
