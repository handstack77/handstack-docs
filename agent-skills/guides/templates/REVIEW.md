# 검토 지침 (HandStack 업무 모듈)

## 검토 분야
각 발견 사항에 분야를 표시한다.
- **연결**: 화면 `transaction` 키 = `.txn` `ServiceID` = SQL id, 입출력 순서·개수, `belongID`, `syn-events` 선언, `AccessScreenID`
- **데이터**: `@Param` 바인딩, 식별자 허용 목록, `Flag`(C/U/D) 분기, `TransactionScope`, 오류 반환 뒤 추가 쓰기, 동시 저장
- **보안**: `Authorize`/`Roles`, 공개 거래 범위, 서버 주입 변수(`@$`) 사용, 비밀·개인정보 노출, 파일 업로드 정책
- **화면**: 빈 결과·입력 오류·업무 거절·성공·결과 불명 상태, 삭제 확인, 접근성, 디자인 규칙
- **준수**: spec.md·plan.md·규칙 표와 일치하는가, 계획에 없던 변경이 있는가
- **반영**: 서버가 읽는 위치, 메뉴·역할 등록, 빌드 배포 부작용

## Important의 의미
동작을 깨뜨리거나, 데이터를 잘못 쓰거나(중복·유실), 권한을 우회하거나, 비밀을 노출하는 사항만 Important로 분류한다. 스타일과 이름은 nit.

## nit 상한
검토당 최대 5개만 보고하고 나머지는 개수로 요약한다.

## 확인 근거 요구
- "정적 검증만 수행"인지 "거래 실행까지 수행"인지 PR에 적혀 있는가
- `hs_inspect.py` 결과(ERROR 0)와 규칙 테스트 표가 첨부됐는가

## 보고하지 않을 사항
생성 파일, 외부 라이브러리 폴더, 자동 점검기가 이미 막는 사항(중복 지적 금지).
